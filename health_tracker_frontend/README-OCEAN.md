# Health Tracker Frontend — Ocean Professional

- Vue 3 + Vite + TypeScript
- Pinia stores for weight, exercise, wellbeing
- API service with mock support
- Dashboard layout with navbar and sidebar
- Responsive UI using Ocean Professional theme tokens

Run with mock data (default):
- VITE_USE_MOCK=true
- npm run dev

Integrate with backend:
- Set VITE_API_BASE_URL to your API origin
- Set VITE_USE_MOCK=false
